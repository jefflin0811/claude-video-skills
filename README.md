# Jeff 的 Claude 影片製作技能庫

在 Claude 的 Customize → Plugins → Add marketplace 輸入本 repo（jefflin0811/claude-video-skills），即可安裝並自動同步更新。

## 外掛
| 外掛 | 內容 |
|---|---|
| video-skills-pack | 影片製作技能包，共 76 個技能：動畫、剪輯、字幕、音效、廣告、產品與衛教影片。說明見 plugins/video-skills-pack/README.md。 |
| jeffs-selection | 姐夫嚴選三系列短影音（探店、開煮、開箱）的固定版型與版型程式。說明見 plugins/jeffs-selection/README.md。 |

每個技能的功能與費用整理在「影音技能清單.txt」。各技能保留原作者授權（MIT／Apache-2.0／AGPL-3.0）。
